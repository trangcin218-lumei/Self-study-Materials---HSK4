# Tự học HSK4
Website tĩnh để tự học HSK4: từ vựng, nhớ chữ tượng hình, ngữ pháp, luyện thi Viết & Đọc (10 đề thi thử), theo dõi tiến độ hằng ngày.

Các file dữ liệu: `data.js` (20 bài), `vocab_data.js` (từ vựng), `grammar_data.js` (ngữ pháp), `hanzi_data.js` (chữ tượng hình), `exam_data.js` (dạng bài luyện thi), `exam_tests.js` (10 đề thi thử).
